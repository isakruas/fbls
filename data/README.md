# Data

Light curves and catalogs for large-scale processing. Nothing here is produced
by the search; it is the input inventory.

```
data/curves/<tic>/sector-N.npz    SPOC 2-minute light curve of one sector (time_bjd, flux, flux_err, centr1, centr2)
data/curves/<tic>/sector-N.json   provenance of the download (product, sector, camera, CCD)
data/catalogs/exofop_toi.csv      ExoFOP TOI table snapshot (dispositions, periods, depths)
data/catalogs/toi.csv, toi.json   TOI catalog snapshots
data/catalogs/known.json          known planets cross-reference
data/targets/<day>/...            target selections and download manifests by day
data/manifest.txt                 one line per star for `fbls batch`: tic pmax files...
data/inventory.csv                per-star summary: sectors, files, reference-set flag, TOI, disposition, catalog period
```

Process everything with

```
target/release/fbls batch --list data/manifest.txt --output-dir results --workers 2 --pmax 20
```

`data/curves/`, `data/catalogs/` and `data/targets/` are excluded from version
control (13 GB of light curves, 130 MB of catalog snapshots); the manifest and
inventory are regenerated by `tools/inventory.py`. Catalog snapshots come from
ExoFOP (`https://exofop.ipac.caltech.edu/tess/download_toi.php?output=csv`) and
the TOI, CTOI, known-planet, eclipsing-binary and TCE tables used by the
vetting stage.
